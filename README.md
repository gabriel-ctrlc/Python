# 🐍 Python — Curso em Vídeo

Repositório destinado aos estudos e exercícios desenvolvidos durante o **Curso de Python** do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor **Gustavo Guanabara**.

O objetivo deste repositório é registrar minha evolução no aprendizado da linguagem Python, reunindo exercícios, desafios e projetos desenvolvidos ao longo do curso.

## 📚 Sobre o curso

O curso apresenta os principais fundamentos da linguagem Python, desde os conceitos iniciais de programação até estruturas mais avançadas.

Durante os estudos, são trabalhados conceitos como:

* Variáveis e tipos de dados
* Operadores
* Entrada e saída de dados
* Condicionais
* Estruturas de repetição
* Listas
* Tuplas
* Dicionários
* Funções
* Modularização
* Tratamento de erros
* Manipulação de arquivos
* Entre outros conceitos de programação em Python
